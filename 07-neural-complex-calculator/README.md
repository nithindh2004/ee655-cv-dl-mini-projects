# Neural Complex-Number Calculator

An MLP that takes two complex numbers and an operation (+, −, ×, ÷) and predicts the real and imaginary parts of the result, trained on synthetic data. A baseline and an improved model show how encoding and normalisation change what the network can learn.

## Approach
MLP regression on synthetic data. **v1**: 5→64→64→2, scalar op code, 100k samples. **v2**: one-hot op, standardised inputs *and* outputs, 8→256→256→128→2 with BatchNorm, Huber loss, cosine LR, gradient clipping, 500k samples.

## Result
| Operation | v1 mean rel. error | v2 mean rel. error |
|---|---|---|
| Addition | 7.3 % | 2.3 % |
| Subtraction | 12.2 % | 2.6 % |
| Multiplication | 76.9 % | 17.7 % |
| Division | 84.8 % | 32.2 % |

Linear ops are learned well; × and especially ÷ (rational in |b|²) remain the hard cases.
